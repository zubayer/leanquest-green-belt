# Lean Green Belt Dojo

A single-file, interactive study app for the **IISE Lean Green Belt** certification exam, built from the 2025-26 course slides (v1.1).

## What's inside
- **11 lessons** following the 5 Lean principles: intuition, analogy, formal detail, worked example, exam traps, plus a 5-question check
- **Practice**: 213 exam-style questions with explanations (by topic, mixed, or weakest topics)
- **Mock exam**: 40 questions, 2-hour timer, 70% to pass (plus a 20-question quick mode)
- **Flashcards**: 72 cards with spaced repetition
- **Games**: Waste Hunter, Order It, Japanese Match, Calc Lab (takt, OEE, %VA, days of inventory), SMED Sorter, Tool to Principle
- **Cheat sheet**: formulas and lists for the open-notes exam

## Run it
No build step and no dependencies. Open `index.html` in a browser.

To host it: GitHub repo **Settings > Pages > Deploy from a branch > main / (root)**.

Progress (XP, streak, scores) is saved in your browser's localStorage only.

## Exam format (per the course)
40 questions, 2 hours, 70% to pass, open notes, no internet.

## Note on the OEE example
The slides give 540 min on the availability slide and 480 min on the performance slide for the anesthesia machine. That yields OEE 78.75% or 70%, so confirm with your instructor's answer key.
